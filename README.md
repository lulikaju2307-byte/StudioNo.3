# Studio No. 3 — интернет-каталог товаров

Адаптивный каталог товаров на чистом HTML/CSS/JavaScript, без фреймворков.

## Что реализовано
- Каталог товаров с карточками (рендеринг через JavaScript)
- Адаптивная вёрстка (Flexbox/Grid)
- Дополнительные страницы: «О нас», «Доставка»

## Технологии
HTML5, CSS3, JavaScript (ES6+)

## Как запустить локально
Скачать репозиторий и открыть index.html в браузере.
